# Simply Screens 0.9.0

- Authorize image-byte downloads using the player's own/legacy-public library, operator access, or a currently tracked display that permits viewing. Recheck authorization before every transfer chunk; an image UUID alone no longer grants access to private media.
- Persist ownership for standalone displays and linked networks. Add trusted players, ownership transfer, and independent PUBLIC, TRUSTED, OWNER_ONLY and OPERATORS policies for viewing and content control. Access management and relinking remain restricted to the owner and operators.
- Add ownership/access controls to the existing Settings tab, including operator claims for legacy unowned displays. Trusting a player does not grant ownership or access to the owner's private library.
- Store versioned, authoritative network records with revision checks and atomic writes/backups. Import legacy image/owner registries without changing Screen IDs or deleting media; refuse unsafe legacy fallback if both the new primary and backup are unreadable.
- Keep aspect ratio local to each physical display and add a local image override for linked displays. Preserve ownership through anchor promotion and split displays, and prevent multiblock merges across different access policies or owners.
- Add shared-state and native packet/service regressions for all supported Minecraft versions. Playlists, redstone controllers, ComputerCraft, and a public integration API remain separate future features.
- Localize access-policy values and show translated On/Off labels for local image overrides instead of enum names and raw booleans.

- Match Simply Speakers ownership settings: owner names, Change owner and Add player dialogs, named viewing/control menus, and a managed trusted-player list. Accept online player names or offline UUIDs.
- Explain local image overrides on hover.
- Refresh access automatically when entering Settings instead of showing a manual refresh button. Add missing tooltips to display settings, access controls, player dialogs, and the theme toggle.
- Match Simply Speakers permission modes: Operators only now excludes non-OP owners from viewing/content control while preserving their access-management rights. Explain the operator override shared by every mode.
- Add optional Patchouli support: a craftable guide in the Screens creative tab, setup and access chapters, and a generated transparent 64x64 book texture. Gate recipes on Patchouli and keep it an optional release dependency.

- Expose personal screen render distance in Settings > Your display settings, import existing values once, and keep server policies separate.

- Confirm network links only after a correlated server acknowledgement; rejected or stale relinks restore authoritative display settings instead of reporting success.
