# Simply Screens 0.8.4

## Changed

- Multi-block screens now maintain an authoritative anchor and safely synchronize structure, image, aspect-ratio, and linked-screen state across chunks.
- Linked screen IDs are now persistent, server-owned resources. Existing ownerless IDs require an administrator to claim them, while administrators retain a maintenance override.
- Screen rendering falls back to replicated child data when an anchor chunk is temporarily unavailable.
- Image transfers use bounded worker queues, per-player concurrency limits, chunk validation, timeouts, and deterministic cleanup.
- Server image and linked-screen registries use safer persistence, backup, and world-switch lifecycle handling.

## Fixed

- Fixed malformed or unauthorized packets modifying screens from invalid positions, excessive distance, unloaded chunks, or without linked-screen ownership.
- Fixed URL image downloads accepting unsafe destinations, redirects, private or local network targets, oversized responses, unsupported content, and invalid filenames.
- Fixed newly placed screens adopting children whose foreign anchor was unloaded.
- Fixed linked screens failing to reconcile with the global registry after their anchor loaded.
- Fixed cross-chunk screens disappearing when the anchor chunk unloaded.
- Fixed absent legacy NBT fields producing invalid zero-sized structures or incorrect aspect-ratio behavior.
- Fixed oversized local images being read into memory before their configured limit was checked.
- Fixed non-successful HTTP responses leaving response bodies open.
- Fixed stale image selections and unsafe image removal or download requests.

## Security and hardening

- Added server-authoritative access, distance, dimension, loaded-chunk, value, and ownership validation to screen update packets.
- Added SSRF protections with DNS/IP validation before connections and after redirects.
- Added strict upload and download limits for total bytes, chunks, active transfers, queued jobs, and transfer lifetime.
- Added image signature and decoder validation before content is published.
- Added regression coverage for URL security, linked-screen ownership, structure indexing, and bounded transfer executors.
