# 0.10.0 — Screen control API and operator commands

- Add an actor-aware Java `ScreenApi` across all five supported Minecraft/loader targets for named network discovery, immutable/redacted status, image selection, saved playlist playback and transport.
- Add synchronous loaded-display inspection by explicit dimension/position, and private-library-safe image enumeration.
- Add logical server-thread `ScreenEvents` for image changes, slideshow start/pause/resume/stop, slide transitions and completion. Event callbacks are queued outside synchronized persistence locks.
- Register `/simplyscreens` with `/screens` alias on Fabric, Forge and NeoForge. Operator-only commands support list/info/status, set/clear, playlist play/transport, media inspection, multi-dimension loaded-display inspection, and targeted refresh.
- Route all write operations through existing authoritative network/playlist services with consistent actor and media ownership checks; do not load chunks to inspect displays.
- Add permission, automation, lifecycle event and failure-isolation regression tests and integration documentation.
- Intentionally advance from 0.9.1 to 0.10.0 for the new public integration surface; no save migration or additional dependencies.
