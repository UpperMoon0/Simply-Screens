# 0.10.0 — Named slide playlists

- Save, search, rename, duplicate and delete personal image playlists. Reorder slides and set each duration from 1 second to 24 hours.
- Play saved snapshots on a physical display or synchronized Screen ID. Editing or deleting a saved playlist does not disrupt the snapshot already playing.
- Pause, resume, stop, next, previous, restart the current slide, repeat none/current/list, and shuffle. One-off Next/Append queues never modify saved slides.
- Display a 10-second announcement and resume the exact interrupted slide/queue offset. End an announcement early from the transport menu.
- Advance the timeline with active server ticks even when linked chunks are unloaded. Pausing single-player or stopping the server does not consume slide duration; opening the playlist editor keeps playback running.
- Follow Simply Speakers' layout: wide sidebar, compact tabs, searchable playlist selector, per-slide actions, separate queue and persistent transport.
- Check current target, revisions, screen permissions and image ownership for every mutation. Ownership transfer invalidates associated playback, including unloaded local overrides.
- Prefetch at most two upcoming, tracked-and-viewable images per viewer every two seconds (8 MiB encoded limit per prefetched image). Bound decoded textures to 32 entries/128 MiB and 16 megapixels per image. Unload old GPU textures while retaining disk cache.
- Preserve existing Screen IDs, ownership/trust controls, physical display identity, local-image overrides, PacketWeave transport and supported loader versions.
- Start the selected saved list from the player when stopped, or start pending queued slides first. Preserve an image when creating a new playlist from its gallery menu, wait for slow refresh replies, keep playback/mode status visible in compact layouts, and truncate long playlist names within their buttons.
