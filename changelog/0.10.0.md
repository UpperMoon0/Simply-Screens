# 0.10.0 — Named slide playlists

- Save, search, rename, duplicate and delete personal image playlists. Drag rows to reorder saved slides or the queue, and set each duration from 1 second to 24 hours.
- Play saved snapshots on a physical display or synchronized Screen ID. Editing or deleting a saved playlist does not disrupt the snapshot already playing.
- Pause, resume, stop, next, previous, restart the current slide, repeat none/current/list, and shuffle. One-off Next/Append queues never modify saved slides.
- Display a 10-second announcement and resume the exact interrupted slide/queue offset. End an announcement early from the slideshow controls menu, which appears only during an announcement.
- Advance the timeline with active server ticks even when linked chunks are unloaded. Pausing single-player or stopping the server does not consume slide duration; opening the playlist editor keeps playback running.
- Use a screen-focused layout: wide sidebar, compact tabs, searchable playlist selector, per-slide actions, separate queue and centered persistent playback controls.
- Check current target, revisions, screen permissions and image ownership for every mutation. Ownership transfer invalidates associated playback, including unloaded local overrides.
- Prefetch at most two upcoming, tracked-and-viewable images per viewer every two seconds (8 MiB encoded limit per prefetched image). Bound decoded textures to 32 entries/128 MiB and 16 megapixels per image. Unload old GPU textures while retaining disk cache.
- Preserve existing Screen IDs, ownership/trust controls, physical display identity, local-image overrides, PacketWeave transport and supported loader versions.
- Start the selected saved list from the slideshow controls when stopped, or show pending temporary slides first. Preserve an image when creating a new playlist from its gallery menu, wait for slow refresh replies, keep playback/mode status visible in compact layouts, and truncate long playlist names within their buttons.

- Require OpenUI MC 0.0.14 or newer on clients, compile against 0.0.14, and build CI dependencies from its pinned drag-fix commit.
- Include the matching optional Patchouli runtime in development environments by default; disable it with `-PscreensPatchouli=false` for optionality checks.

- Use screen and slideshow terminology throughout the interface and guide: Displaying, Start, Show next, Up next, Loop and Saved/Random order. Show readable loop/order values in tooltips.
- Reformat every guide entry into shorter paragraphs and smaller pages with explicit paragraph breaks.
- Fix stuck drag previews by requiring the OpenUI 0.0.14 pointer-cancellation patch; Escape, row removal, interrupted releases and failed drops no longer retain the preview or mouse capture.
- Use a single-row slideshow toolbar with generated 64x64 loop/order mode icons and tooltips. Keep elapsed time beside the displayed image, and omit duplicate status/mode text.
- Remove repeated Up next headings, empty previews, unusable empty-queue actions and redundant image-selection confirmations; wrap long empty-state guidance.

- Replace all remaining pixel transport, action and theme glyphs with matching 64×64 texture icons. Theme controls use compact icons with action tooltips.
