# 0.8.10

- Use PacketWeave for upload/download chunking and bounded reassembly across all five targets.
- Reject oversized packet arrays before allocation, duplicate chunks, changed envelopes, and unsafe download extensions.
- Bind upload transactions to their sender, world, and screen; clean retained transfers on expiry and disconnect.
- Bound processing memory and worker-to-game-thread download dispatch.
- Require standalone PacketWeave 0.1.1 or newer on both clients and servers, with matching Minecraft/loader artifacts. Declare it in loader metadata and CurseForge file relations; compile the pinned public API without bundling a second copy.
- Keep partial uploads and cleanup independent of slow image storage, and prevent timeout retries from overlapping active downloads.
- Preserve existing media/world data and wire packet formats; add PacketWeave when upgrading from 0.8.9.
- Document the actual configuration keys, defaults, installation, and development runtime setup.
