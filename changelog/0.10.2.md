# Simply Screens 0.10.2

- Prevent image uploads and downloads from flooding the game connection on slow Wi-Fi and mobile data.
- Use shared PacketWeave connection budgets, 4 KiB chunks and receiver receipts before sending more media.
- Read upload files, ingest incoming images, write caches and decode received images on bounded workers. Create textures on the render thread.
- Bind image download packets to unique request IDs; reject stale, excessive and stalled transfers without disconnecting players.
- Validate and decode complete images **before** atomically publishing cache files; malformed downloads cannot poison the cache or block a valid retry.
- Release failed/rejected transfers from the 30-second in-flight reservation and use a separate two-second retry cooldown, avoiding both blank screens until timeout and per-frame retry storms.
- Serialize the final cache generation/request/peer check and atomic publication with invalidation and disconnect cleanup; cancelled workers discard their staged files and decoded images rather than restoring stale media.
- Require PacketWeave 0.1.5 or newer. Update clients and servers together because the media packet format changed. Existing image libraries and caches remain compatible.
