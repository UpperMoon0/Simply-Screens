# Simply Screens 0.8.9

## Fixes

- Fixed distance-dependent screen image z-fighting while keeping images visually flush with the screen surface.
- Preserved normal foreground occlusion instead of using see-through rendering.
- Preserved PNG transparency and semi-transparent blending in the custom 1.21.1 and 26.1.2 screen render paths.

## Verification

- Added real framebuffer regression coverage across every supported loader/version, facing, distance, angle, occlusion, reload, and cross-chunk case.
- Added transparent and semi-transparent image coverage so alpha/blending regressions fail the visual gate.
- Negative controls reproduce the old depth conflict and foreground leakage before the fixed renderer can certify the change.
